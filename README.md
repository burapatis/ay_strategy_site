## วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่นชื่อ `ayutthaya-education-strategy`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repository โดยให้ `index.html` อยู่ที่ระดับบนสุด
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก `Deploy from a branch`
5. ที่ **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
6. รอประมาณ 1–2 นาที เว็บไซต์จะเผยแพร่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

ไฟล์ `.nojekyll` มีไว้เพื่อให้ GitHub Pages ไม่ประมวลผลไฟล์ผ่าน Jekyll ซึ่งจำเป็นสำหรับเว็บไซต์แบบ static ธรรมดา **อย่าลบไฟล์นี้**

เว็บไซต์สาธารณะอยู่ที่ `https://ayeduplan2.thamdee.com/` ไฟล์ `robots.txt` และ `sitemap.xml` ชี้ไปที่อยู่นี้แล้ว ค้นหาและโซเชียลจะใช้ `assets/og-image.png` เป็นภาพตัวอย่างเมื่อแชร์ลิงก์

## การแก้ไขเนื้อหา

เว็บไซต์นี้เป็น HTML ธรรมดา ไม่ต้องติดตั้งเครื่องมือใด แก้ไขได้โดยตรงด้วยโปรแกรมแก้ไขข้อความทั่วไป

- **เปลี่ยนสี** แก้ที่ตัวแปรในส่วน `:root` ของ `assets/style.css`
- **ระบบสี** เว็บไซต์ใช้ชุดสี 7 สีที่สื่อความหมาย ไม่ใช่การตกแต่ง โดยแต่ละสีแทนหนึ่งขั้นของลูกโซ่การตรวจสอบย้อนกลับ ไล่จากสีอุ่นซึ่งคือสิ่งที่เราลงมือทำ ไปสู่สีเย็นซึ่งคือหลักฐานที่ยืนยัน ตัวแปรคือ `--c1` ถึง `--c7` และใช้ซ้ำในแถบสีบนสุดของทุกหน้า แผนภาพหน้าแรก หน้าตัวอย่างลูกโซ่ แถบสีของการ์ด และไอคอน **หากเปลี่ยนสีใดสีหนึ่ง ต้องเปลี่ยนให้สอดคล้องกันทั้งระบบ**
- **เพิ่มหน้าใหม่** แก้เนื้อหาในส่วน `<main>` ของไฟล์ HTML ใหม่ จากนั้นเพิ่มลิงก์ในส่วนหัวและส่วนท้ายที่ `assets/site.js` ครั้งเดียว และเพิ่มรายการใน `assets/search-index.js` กับเมนูสำรองใน `<noscript>` ของหน้าใหม่
- **แปลงเอกสาร Markdown** แก้ไฟล์ใน `docs/` แล้วรัน `python3 tools/render_docs.py` จากโฟลเดอร์ราก ต้องติดตั้งแพ็กเกจ `markdown` ก่อนครั้งแรก (`pip3 install markdown`) สคริปต์จะสร้างหน้า `.html` คู่กันและอัปเดตดัชนีค้นหา อย่าแก้ไฟล์ `.html` ใน `docs/` โดยตรง
- **ฟอนต์** ใช้ IBM Plex Sans Thai สำหรับเนื้อหา และ Trirong สำหรับหัวเรื่อง โหลดจาก Google Fonts ตอนเปิดบนจอ เมื่อพิมพ์จะใช้ฟอนต์ในเครื่อง เช่น Thonburi และ Noto Sans Thai หากโหลดจากอินเทอร์เน็ตไม่ได้

## ข้อควรทราบก่อนนำเนื้อหาไปใช้

เว็บไซต์นี้ **ไม่ใช่เอกสารทางการ** ของสำนักงานศึกษาธิการจังหวัดพระนครศรีอยุธยาหรือหน่วยงานใด

- ค่าฐานการออกกลางคันขัดแย้งกัน 10.7 เท่า ระหว่างแผนของหน่วยงาน (1,181 คน) กับรายงานสถิติจังหวัด (110 คน) ยังไม่มีข้อยุติ
- มีข้อมูลจำแนกรายอำเภอครบ 16 อำเภอแล้ว และประเด็นยุทธศาสตร์ที่ 2 มีค่าฐานระดับจังหวัดจากดัชนีความก้าวหน้าของคนแล้ว แต่ยังไม่มีผลสัมฤทธิ์รายโรงเรียนครบทุกสังกัด
- ตัวเลขจำนวนครูและห้องเรียนของภาคเอกชนมีความผิดปกติที่ยังอธิบายไม่ได้ ห้ามใช้ก่อนตรวจสอบนิยาม
- ข้อมูลกฎหมายยังไม่ได้ตรวจทานกับตัวบทในราชกิจจานุเบกษาทุกฉบับ
- ร่างยุทธศาสตร์ฉบับกรณีตัวอย่างใน `docs/` มีตัวเลขสมมติที่กำกับไว้ในเอกสาร **ห้ามนำไปอ้างอิง**

รายละเอียดข้อจำกัดทั้งหมดอยู่ในหน้า `about.html`

**ตัวเลขที่สำคัญที่สุดของงานนี้** ณ มกราคม 2569 จังหวัดพระนครศรีอยุธยามีเด็กอายุ 0 ปี 4,610 คน
และเยาวชนอายุ 17 ปี 9,665 คน คิดเป็นร้อยละ 47.7 หมายความว่าในเวลา 17 ปี ขนาดรุ่นเด็กเกิดใหม่
ลดลงเหลือไม่ถึงครึ่ง และประชากรวัยเรียนภาคบังคับจะลดลงร้อยละ 23.2 ภายในปี 2575
ตัวเลขนี้ไม่ใช่การคาดการณ์ เพราะเด็กเหล่านี้เกิดและมีชื่อในทะเบียนราษฎรแล้ว
